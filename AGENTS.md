2. Named exports везде (не default).
3. Никаких внешних runtime-зависимостей, кроме vite (dev). UI-библиотеки, state-менеджеры, CSS-фреймворки — запрещены.
4. Файлы держим маленькими. Если файл > 200 строк — сигнал разбить.
5. Никакой преждевременной абстракции. Не создавай папки/файлы «на будущее».
6. Комментарии — только там, где код неочевиден (формулы, workaround'ы). Не комментируй очевидное.
7. CSS — обычный, один styles.css (плюс позже per-mode по необходимости). Не тяни Tailwind.
8. Не пиши тесты, если я явно не попросил.
9. Не добавляй ESLint/Prettier/CI, если не попросил.
10. Git-коммиты: conventional commits (feat/fix/chore/refactor/docs), сообщения на английском, императив.
11. После каждого шага ты:
    a) запускаешь `npm run build` и убеждаешься, что сборка проходит без ошибок TS;
    b) делаешь git commit с указанным сообщением;
    c) пишешь краткий отчёт: что сделано, какие файлы созданы/изменены, что проверить руками.
